# Visual QA

Compared source https://www.twelvelabs.io/?ref=land-book.com with local `/` at 1440.

## Matches
- Verbatim copy across hero, get-started, workflows, KPIs, solutions, security, models, stories, CTA, footer
- Milling Duplex / Triplex, paper `#F4F3F3`, ink `#1D1C1B`
- Banner, sticky glass header, pill CTAs with arrow
- Dark / light section rhythm
- Click-driven get-started + workflow accordions

## Remaining gaps
- Hero mosaic is a CSS video grid (same source clips as the live Three.js canvas), not the WebGL camera arc
- Get-started API/MCP/Integrations are title-only (live default; JS click did not expose extra copy)
- Highlight/insights workflow images reuse search/segment assets
- Nav dropdowns are simple lists, not Framer mega-menus
- Cookie + language widgets omitted
